# Security policy

`llama-autotune` launches local `llama.cpp` binaries and inspects local hardware/model files. It does not intentionally send prompts, models, hardware inventory, or tuning results to a remote service.

Please avoid posting sensitive logs in public issues. Reports may contain local paths, device identifiers, build metadata, model names, and runtime details.

For a security-sensitive report, contact the repository owner privately through GitHub rather than opening a public issue.

This project is an early-stage local systems tool. Review generated commands before using them on shared or production machines.
